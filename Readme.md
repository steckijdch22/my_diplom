# ZeroDoc: Защищенная система совместной работы

Программный комплекс для распределенного редактирования документов, реализующий концепцию **Zero-Knowledge** и алгоритмы бесконфликтной синхронизации **CRDT (Yjs)**.

## 🌟 Ключевые особенности

- **Сквозное шифрование (E2EE):** Данные шифруются в браузере (AES-GCM 256). Сервер не имеет доступа к содержимому.
- **Синхронизация реального времени:** Использование WebSockets (Socket.io) для мгновенного обмена правками.
- **Отказоустойчивость:** Многоуровневое хранение (Hot cache в Redis + Persistence в PostgreSQL).
- **Безопасность сессий:** JWT-авторизация через защищенные HttpOnly Cookies.
- **Управление ключами:** Хранение приватных ключей в IndexedDB и поддержка экспорта в формат PKCS8 (.key файлы).

## 🛠 Технологический стек

- **Frontend:** React, TypeScript, Tailwind CSS, Quill.js, Yjs.
- **Backend:** NestJS, Prisma ORM, Socket.io.
- **Infrastructure:** Docker, Nginx, PostgreSQL, Redis.

## 🚀 Быстрый запуск

Система полностью контейнеризирована. Для запуска не требуется установка Node.js или СУБД на хост-машину.

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/steckijdch22/my_diplom.git
   cd my_diplom
   ```

2. **Подготовьте файл окружения:**
   Создайте файл `.env` в корневой директории на основе примера:

   ```env
   DB_USER=postgres
   DB_PASSWORD=my_secure_password_2026
   DB_NAME=zerodoc_db
   DB_PORT=5432
   REDIS_PORT=6379
   JWT_SECRET=super_long_random_secret_string
   VITE_BACKEND_URL=http://localhost:3000
   CLIENT_URL=http://localhost
   DATABASE_URL=postgresql://postgres:my_secure_password_2026@db:5432/zerodoc_db?schema=public
   ```

3. **Запустите систему одной командой:**

   ```bash
   docker compose up -d --build
   ```

4. **Доступ к интерфейсу:**
   - **Frontend:** [http://localhost](http://localhost) (Порт 80)
   - **Backend API:** [http://localhost:3000](http://localhost:3000)

## 📋 Порядок проверки функционала

1. **Регистрация:** При создании аккаунта браузер автоматически предложит скачать `.key` файл. Это ваш единственный способ восстановить доступ.
2. **Создание:** Создайте зашифрованный документ на Dashboard.
3. **Синхронизация:** Откройте документ в двух разных браузерах (или в режиме инкогнито). Убедитесь в мгновенном отображении правок и курсоров.
4. **Безопасность:** Проверьте вкладку "Network". Все пакеты `sync-update` передаются в зашифрованном бинарном виде.
